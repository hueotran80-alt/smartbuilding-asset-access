# Mobile

Web hiện đã được đóng gói dạng PWA (`display: standalone`) nên có thể Add to Home Screen trên Android/iOS.

Khi cần APK/IPA native:
- Có thể bọc cùng frontend bằng Capacitor.
- Mobile dùng cùng Auth/API.
- Sinh trắc học điện thoại chỉ là lớp xác thực cho tài khoản; không thay thế R558S tại cửa.
